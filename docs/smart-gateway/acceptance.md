- 7 项导航在 sidebar / top / 窄窗下可用；设置能进本地代理并返回。
- 启动 15828；绑定 Claude Code 后 `/model` 能看到网关模型范围。

- 隐藏一个上游模型 → OpenCode 配置跟着变。

## 阶段 B

- 请求模型为 `auto` / `claude.auto` 时落到目录第一项。
- 档案 `fallback_mode=model_chain` 时备用模型生效；显式 pin 不切换。

## 阶段 C

- 直连与官方连接不被网关改写。
